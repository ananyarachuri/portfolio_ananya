# Ananya Rachuri — Portfolio

React 18 + Framer Motion, built with Vite.

## Run locally
npm install
npm run dev

## Deploy
npm run build   # outputs to dist/
Drag `dist/` onto Netlify, or import the repo into Vercel (framework: Vite).

## Edit content
All text lives in `src/data.js` (experience, projects, impact numbers, skills).
Artifact slots are in the `Artifacts` component in `src/App.jsx`.
